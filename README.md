
# Public Transport Demand Analysis

## Project Overview
An end-to-end data analytics project to analyze public transport demand, trip trends, and service performance.

## Tools Used
- Python
- NumPy
- Pandas
- Microsoft Excel
- Power BI
- DAX

## Interactive Dashboard

[**Click here to view the Power BI Dashboard**](YOUR_POWER_BI_PUBLIC_LINK)

## Key Analysis
- Total trips and demand trends
- Route-wise analysis
- On-time, delayed, and cancelled trips
- Monthly and yearly trends
- Interactive slicers and KPI measures
